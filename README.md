# Multi-Platform Dynamic UTM Builder

A lightweight, zero-dependency open-source web utility designed for performance marketers, media buyers, and e-commerce teams to generate accurate tracking URLs with native dynamic macros across major ad platforms.

## Supported Ad Platforms & Dynamic Macros
- **Meta Ads (Facebook & Instagram):** `{{campaign.name}}`, `{{adset.name}}`, `{{ad.name}}`, `{{placement}}`
- **TikTok Ads:** `__CAMPAIGN_NAME__`, `__AID_NAME__`, `__CID_NAME__`
- **Snapchat Ads:** `{{campaign.name}}`, `{{adSet.name}}`, `{{ad.name}}`
- **Google Ads:** `{campaignid}`, `{keyword}`, `{creative}`, `{matchtype}`

## Why This Tool?
Manual UTM tagging often leads to broken URLs, inconsistent naming conventions, and lost attribution data in WooCommerce, Shopify, and GA4. This tool automatically formats query strings and preserves native platform macros without breaking URL encoding.

## Quick Start
1. Clone or download this repository.
2. Open `index.html` in any browser, or host it directly via **GitHub Pages**.
